# Logo history notes

Generated alongside data/logos.json. For every company: the logo versions in the manifest (start month, file, source) and the doubts. Sources are Wikimedia Commons / Wikipedia file pages (descriptions and Wikipedia infobox captions give the dates) and 1000logos.net company pages (year headers give the dates). "Only the year is known" means the manifest uses January.

Conventions: a logo that was already in use before the game starts is listed from the first year the source supports (or from the game start where the sources give no date, flagged below). When two sources disagree the later date was used so that no player sees a logo too early.
